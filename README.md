# 🔐 Secure File Vault

A simple Python desktop application for encrypting and decrypting files using a password.

## Features

- 🔒 Encrypt files
- 🔓 Decrypt encrypted files
- 🔑 Password protection
- 📁 File selection
- 🖥️ Simple desktop GUI

## Technologies

- Python
- Tkinter
- Cryptography
- Fernet Encryption
